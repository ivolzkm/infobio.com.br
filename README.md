## 💡 Sobre o Projeto

O **InfoBio.com.br** é uma plataforma open source que visa centralizar o conhecimento e fortalecer a comunidade de Informática Biomédica no Brasil. O projeto foi criado para resolver a dispersão de recursos, oportunidades de carreira e espaços de discussão na web, que dificultam o acesso e a colaboração na área.

Nossa plataforma serve como:

-   📚 **Hub de Conhecimento:** Com artigos, tutoriais e guias de estudo sobre bioinformática, informática clínica e saúde digital.
-   🤝 **Comunidade Ativa:** Um fórum para troca de ideias, dúvidas e networking entre estudantes e profissionais.
-   💼 **Portal de Oportunidades:** Um mural dedicado a vagas de estágio, emprego e pesquisa na área.
-   🛠️ **Vitrine de Projetos:** Um espaço para que membros da comunidade possam divulgar seus projetos e portfólios.

## 🗺️ Roadmap do Projeto

Nosso plano de desenvolvimento está dividido em fases para guiar a construção da plataforma.

-   [x] **Fase 1: Fundação e Conteúdo (MVP)**
    -   [x] Estrutura inicial do site (Landing Page).
    -   [x] Sistema de Blog/Artigos (CMS Headless ou similar).
    -   [x] Design e identidade visual inicial.
    -   [x] Seção "Sobre" e "Recursos".
    -   [x] Deploy da versão inicial.

-   [ ] **Fase 2: Construção da Comunidade**
    -   [ ] Integração de um sistema de Fórum de discussão.
    -   [ ] Sistema de perfis de usuário.
    -   [ ] Implementação da Newsletter.

-   [ ] **Fase 3: Ferramentas e Oportunidades**
    -   [ ] Desenvolvimento do Mural de Vagas.
    -   [ ] Criação da galeria "Showcase de Projetos".

-   [ ] **Fase 4: Expansão**
    -   [ ] Internacionalização (conteúdo em inglês).
    -   [ ] Desenvolvimento de pequenas ferramentas web para análises biomédicas.

Você pode acompanhar e sugerir tarefas na nossa aba de [**Issues**](https://github.com/ivolzkm/infobio.com.br/issues)!

## 💻 Tecnologias

A stack tecnológica do projeto inclui:

-   **Frontend:** [Next.js](https://nextjs.org/) / [React](https://reactjs.org/)
-   **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
-   **Backend:** [Node.js](https://nodejs.org/)
-   **Banco de Dados:** [PostgreSQL](https://www.postgresql.org/)
-   **CMS:** [Strapi](https://strapi.io/) ou [Sanity](https://www.sanity.io/)
-   **Deploy:** [Vercel](https://vercel.com/) (Frontend) e [Railway](https://railway.app/) (Backend)

## ✨ Como Contribuir

Toda contribuição é bem-vinda para nos ajudar a construir a maior comunidade de Informática Biomédica do Brasil.

### Guia Rápido para Contribuir com Código:

1.  **Faça o Fork** do projeto.
2.  **Clone** o repositório: `git clone https://github.com/ivolzkm/infobio.com.br.git`
3.  **Crie uma Branch** para sua modificação: `git checkout -b feature/sua-feature`
4.  **Faça o Commit** de suas mudanças: `git commit -m 'feat: Adiciona sua feature'`
5.  **Envie** para o seu repositório (Fork): `git push origin feature/sua-feature`
6.  Abra um **Pull Request** no repositório original.
